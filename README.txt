FREE HOSTING WITH GITHUB PAGES
1. Sign in to GitHub or create a free account.
2. Create a new public repository, for example: from-ideas-to-startups
3. Extract this ZIP on your computer.
4. In the repository, choose Add file > Upload files.
5. Upload index.html (and this README if you wish), then commit the changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch.
8. Select the main branch and /(root), then Save.
9. Wait for GitHub Pages to publish. The website address will be shown in Settings > Pages.

The site is static and does not require a paid server, database, account system or API key.
The interactive quiz, finance calculator and startup idea-sheet download run in the visitor's browser.
